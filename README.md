# java-filmorate

Filmorate — приложение на Spring Boot для работы с фильмами, пользователями, лайками, жанрами, возрастными рейтингами
MPA, заявками в друзья и подтверждённой дружбой.

## Схема базы данных

![Схема базы данных Filmorate](docs/filmorate-db-schema.png)

Редактируемая версия схемы: https://dbdiagram.io/d/Filmorate-DB-6a3d31ded0074fe75d2305df

Модель дружбы разделена на две таблицы:

- `friend_requests` хранит неподтверждённые однонаправленные заявки в друзья;
- `friendships` хранит подтверждённую дружбу между двумя пользователями.

Пара пользователей в `friendships` хранится в нормализованном виде: меньший id записывается в `first_id`, больший id — в
`second_id`. Это защищает от дублей вроде `3-7` и `7-3`.

Лайки фильмов и жанры фильмов вынесены в отдельные связующие таблицы. Таблица `films` ссылается на справочник
`mpa_ratings`, а таблица `film_genres` связывает фильмы со справочником `genres`.
